# AI Trust Check

생성형 AI 답변의 신뢰성을 **규칙 기반 전향추론**으로 검증하는 교육용 Python 전문가 시스템입니다.

## 소개

사용자가 AI 답변과 출처를 직접 확인하고 9개의 검증 항목에 답하면,
프로그램이 입력된 초기 Fact(사실)에 규칙을 연쇄 적용합니다.
단순 점수제가 아니라 **중간 Fact를 생성하고 다음 추론에 사용하는 방식**입니다.

최종 결과는 `신뢰 조건 충족`, `추가 검증 필요`, `신뢰도 낮음` 중 하나입니다.
AI 답변의 절대적 진실을 자동으로 보증하는 시스템은 아니며, LLM/API를 사용하지 않습니다.

## 검증 항목

| 항목 | 확인하는 내용 |
| --- | --- |
| F1 출처 제시 | 답변에 출처가 있는가 |
| F2 출처 접근 가능 | 출처가 실제로 존재하고 접근 가능한가 |
| F3 출처 신뢰성 | 공식 문서·논문 등 신뢰할 만한 출처인가 |
| F4 AI 주장 뒷받침 | 실제 출처 내용이 AI 주장을 뒷받침하는가 |
| F5 교차검증 | 독립적인 다른 자료에서도 확인되는가 |
| F6 최신성 | 최신성이 중요한 질문인 경우, 답변의 정보가 현재 시점에도 유효한가 |
| F7 구체적 사실 근거 | 날짜·수치 등 구체적인 주장에 확인 가능한 근거가 있는가 |
| F8 내부 일관성 | 답변 내부에 모순이 없는가 |
| F9 불확실성 표시 | 불확실한 내용을 적절히 표시했는가 |

`1=예`, `2=아니오`로 입력하며, F6·F7·F9는 `3=해당 없음`도 허용합니다.
해당 없음은 실패로 처리하지 않습니다.

F6은 최신성이 중요하고 현재에도 유효하면 **예**, 오래된 정보를 현재 정보처럼
제시했다면 **아니오**, 최신성이 중요하지 않으면 **해당 없음**입니다.
예를 들어 “지금 시즌 몇까지 나왔어?”에 오래된 정보를 답하면 아니오,
“시즌1은 몇 년에 방영됐어?”처럼 고정된 과거 사실을 물으면 해당 없음입니다.

출처가 없으면 F2~F5, 출처에 접근할 수 없으면 F3~F5를 자동으로 건너뛰고
`미확인`으로 처리합니다. 검증 부족만 있으면 추가 검증 필요로 판정하고,
실제 반증(F4)·최신성 실패(F6)·내부 모순(F8)이 확인되면 신뢰도 낮음으로 판정합니다.

## 동작 방식

```text
초기 Fact → 규칙 적용 → 중간 Fact 생성 → 추가 규칙 적용 → 최종 신뢰성 판단
```

검증은 **외부 근거 검증**, **사실 정보 검증**, **답변 자체 신뢰성**의 세 축으로 진행됩니다.
예를 들어 출처 제시와 접근 가능이 확인되면 ‘출처 추적 가능’이라는 중간 Fact가
생기고, 이 사실이 다음 규칙의 조건이 됩니다.
실행 화면에서 규칙의 발화 이유, 새 Fact, 최종 결과를 확인할 수 있습니다.

## 실행 방법

Python 3.10 이상에서 별도 패키지 설치 없이 프로젝트 루트에서 실행합니다.

```bash
python3 main.py
```

모듈 실행도 지원합니다.

```bash
python3 -m ai_trust_check
```

## 프로젝트 구조

```text
│   ├── engine.py      # Working Memory와 전향추론 엔진

├── tests/
├── main.py            # 실행 진입점
└── README.md
```
